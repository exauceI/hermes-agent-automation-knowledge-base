# Hermes Agent — Cours et automatisation

Ce dépôt rassemble une formation progressive pour utiliser Hermes Agent, de l'installation locale jusqu'à l'exploitation d'un agent déployé et automatisé.

> Les commandes et recommandations sont vérifiées contre la [documentation officielle Hermes Agent](https://hermes-agent.nousresearch.com/docs/). Les exemples ne contiennent ni clé API, ni token de bot, ni secret.

## Parcours prévu

1. **Fondations** — installation, vérification, modèle et outils.
2. **Configuration** — profils, fournisseurs, outils, mémoire et skills.
3. **Automatisation** — cron, scripts, tâches récurrentes et alertes.
4. **Messagerie** — gateway, Telegram et contrôle des accès.
5. **Déploiement** — service utilisateur, observabilité, sauvegarde et mise à jour.
